\begin{center}
    \textbf{\textit{Streszczenie}}
\end{center}

% \indent Praca inżynierska przedstawia projektowanie układu sterowania i nadzoru dla aktywnego uchwytu zwanego także goniometrem, który pozwala stabilizować zadaną orientację instrumentu optycznego (np. teleskopu). Głównym celem  jest zapewnienie zdalnego sterowania z możliwością zadawania trajektorii oraz śledzenia zadanej pozycji. Ruch konstrukcji zachodzi za pomocą mechanizmu śrubowego połączonego z silnikami krokowymi, co umożliwia zmianę położenia układu w osiach X i Y. Zarządzanie sygnałami referencyjnymi odbywa się z poziomu aplikacji webowej, która komunikuje się z urządzeniem za pośrednictwem protokołu Ethernet. Serwer do komunikacji został zaimplementowany na mikrokontrolerze przy użyciu systemu czasu rzeczywistego FreeRTOS. Odczyt aktualnej pozycji umożliwia interfejs SPI, a uzyskane dane są następnie wykorzystywane w pętli sprzężenia zwrotnego do regulacji położenia. W tym celu zastosowano regulator dwupołożeniowy z elementem strefy nieczułości.

\begin{center}
    \textbf{\textit{Abstract}}
\end{center}

% \indent The engineering thesis presents the design process of a control and monitoring system for a goniometer, which allows for stabilizing the desired orientation of an optical instrument (e.g., a telescope). The main goal of the goniometer was to facilitate remote control with the capability to define trajectories and attain the target position. The actuation of the structure is achieved by using a screw mechanism connected to stepper motors, allowing the system's position to be adjusted along the X and Y axes. Signal reference management is carried out through a web application that communicates with the device via the Ethernet protocol. The communication server has been implemented on a microcontroller using FreeRTOS, a real-time operating system. Data is received via the SPI interface and is used in a feedback loop for position regulation, with a two-position regulator featuring a dead zone.
